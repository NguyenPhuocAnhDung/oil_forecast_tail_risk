# Analysis Report: Statistical Validation and Metrics Compilation for 32 Models

## 1. Executive Summary
This report analyzes the statistical validation and metrics compilation requirements for the 32 models evaluation under Milestone B of the GUM-Net Research OS upgrade. It provides a mathematical formulation and optimized design for three key scripts:
- `dm_test_32models.py`: Diebold-Mariano (DM) test with Newey-West HAC variance estimator and Model Confidence Set (MCS) block bootstrap.
- `effect_size_32models.py`: Non-parametric effect size comparison via Cliff's Delta ($\delta$) and Vargha-Delaney $A_{12}$ using an optimized $O(n \log n)$ rank-based algorithm.
- `compile_32model_results.py`: Multi-seed aggregation and calculation of point/interval metrics (MAE, RMSE, DA, PINAW) with temporal filtering.

## 2. Diebold-Mariano Test & Model Confidence Set (MCS) Formulation

### 2.1. Diebold-Mariano Test with Newey-West HAC Estimator
Let $e_{1, t}$ and $e_{2, t}$ be the forecast errors of model 1 and model 2 at time $t$. The loss differential is defined as:
$$d_t = L(e_{1, t}) - L(e_{2, t})$$
where $L(e) = |e|$ for MAE, and $L(e) = e^2$ for MSE. The sample mean differential is $\bar{d} = \frac{1}{T} \sum_{t=1}^T d_t$.

Under the null hypothesis of equal predictive ability, $H_0: E[d_t] = 0$. The test statistic is:
$$DM = \frac{\bar{d}}{\sqrt{\widehat{\text{Var}}(\bar{d})}}$$
To account for autocorrelation and heteroskedasticity in the loss differential series (especially for multi-step ahead forecasts $h > 1$), the variance of the mean $\widehat{\text{Var}}(\bar{d})$ is estimated using the Newey-West HAC estimator with a Bartlett kernel:
$$\widehat{\text{Var}}(\bar{d}) = \frac{1}{T} \left[ \hat{\gamma}_0 + 2 \sum_{k=1}^q \left( 1 - \frac{k}{q + 1} \right) \hat{\gamma}_k \right]$$
where:
- $\hat{\gamma}_k = \frac{1}{T} \sum_{t=k+1}^T (d_t - \bar{d})(d_{t-k} - \bar{d})$ is the sample autocovariance at lag $k$.
- $q$ is the truncation lag (bandwidth). We use the methodology-consistent lag truncation:
  $$q = \max\left(0, \min\left(h - 1, \lfloor 1.2 T^{1/3} \rfloor\right)\right)$$
- To adjust for small-sample bias at long horizons, we apply the Harvey-Leybourne-Newbold (1997) correction:
  $$DM_{HLN} = DM \times \sqrt{\frac{T + 1 - 2h + \frac{h(h - 1)}{T}}{T}}$$

### 2.2. Model Confidence Set (MCS) Test
The MCS test (Hansen et al., 2011) determines the "superior set of models" $\mathcal{M}^* \subseteq \mathcal{M}_0$ at significance level $\alpha$ (typically $\alpha=0.10$).
Let $\mathcal{M}$ represent the set of candidate models (starting with $|\mathcal{M}_0| = 32$). The null hypothesis is:
$$H_{0, \mathcal{M}}: E[d_{ij, t}] = 0, \quad \forall i, j \in \mathcal{M}$$
We use the $T_{\max}$ test statistic:
$$T_{\max} = \max_{i \in \mathcal{M}} t_{i\cdot}$$
where:
- $\bar{d}_{i\cdot} = \frac{1}{|\mathcal{M}| - 1} \sum_{j \in \mathcal{M}, j \neq i} \bar{d}_{ij}$ is the average loss differential of model $i$ relative to all other remaining models in the set.
- $t_{i\cdot} = \frac{\bar{d}_{i\cdot}}{\sqrt{\widehat{\text{Var}}(\bar{d}_{i\cdot})}}$ is the studentized statistic.
- $\widehat{\text{Var}}(\bar{d}_{i\cdot})$ is the Newey-West HAC variance of the series $d_{i\cdot, t} = \frac{1}{|\mathcal{M}| - 1} \sum_{j \neq i} d_{ij, t}$.

#### The original script bug:
In the original `scripts/model_confidence_set.py`, the bootstrap p-value for the pairwise DM test was computed as:
```python
p_val = 2 * min(np.mean(boot_means >= d_mean), np.mean(boot_means <= d_mean))
```
Since `boot_means` is generated by bootstrapping the original loss differential $d_t$ directly, it is centered around the sample mean $d_{\text{mean}}$. Thus, `np.mean(boot_means >= d_mean)` is always approximately $0.5$, which forces `p_val` to always be near $1.0$, failing to reject the null hypothesis even when the models differ drastically.

#### The corrected bootstrap p-value:
To test the null hypothesis $H_0: E[d] = 0$, the bootstrap distribution must be centered. Under the null, the expected value of the mean is 0. So we center the bootstrap means:
$$\bar{d}^{*, b}_{\text{centered}} = \bar{d}^{*, b} - \bar{d}$$
The two-sided bootstrap p-value is the proportion of centered bootstrap means that exceed the observed mean in absolute value:
$$p\text{-value} = \frac{1}{B} \sum_{b=1}^B I\left(\left|\bar{d}^{*, b} - \bar{d}\right| \geq \left|\bar{d}\right|\right)$$
where $B = 1000$ iterations.

### 2.3. Computational Optimization for 32 Models
Running the joint MCS bootstrap with 1000 iterations for 32 models across 7 horizons and 2 targets can be slow if implemented naively. We propose two major optimizations:
1. **Pre-generated Bootstrap Indices**: Since all models are evaluated on the same aligned dates, we can generate a single circular block bootstrap index matrix of shape `[B, T]` for each target/horizon combination. The bootstrapped loss for any model $i$ is obtained by simple indexing: `loss_boot = loss[boot_indices]`.
2. **Original Variance Scaling (Asymptotic Equivalence)**: Rather than recomputing the Newey-West HAC variance on all $B=1000$ bootstrap replicates (which is extremely slow), we approximate the studentized bootstrap statistics by scaling with the sample HAC standard error of the original series:
   $$t_{i\cdot}^{*, b} \approx \frac{\bar{d}_{i\cdot}^{*, b} - \bar{d}_{i\cdot}}{\sqrt{\widehat{\text{Var}}_{HAC}(\bar{d}_{i\cdot})}}$$
   This reduces the computational complexity from $O(B \cdot M^2 \cdot T)$ to $O(M^2 \cdot T + B \cdot M^2)$, allowing the MCS test to execute in under a second.

## 3. Cliff's Delta and Vargha-Delaney A Effect Size Metrics

### 3.1. Mathematical Definitions and Equivalence
To measure the practical significance (effect size) of the forecasting performance differences, we use non-parametric effect sizes on the absolute error distributions of the models.

- **Cliff's Delta ($\delta$)**:
  Cliff's Delta measures the probability that a value selected from Group 1 is larger than a value from Group 2, minus the reverse probability:
  $$\delta = P(X_1 > X_2) - P(X_1 < X_2)$$
  For empirical samples, it is calculated as:
  $$\delta = \frac{1}{n_1 n_2} \sum_{x \in X_1} \sum_{y \in X_2} \text{sign}(x - y)$$
  where $\text{sign}(u) = 1$ if $u > 0$, $-1$ if $u < 0$, and $0$ if $u = 0$. $\delta \in [-1, 1]$.

- **Vargha-Delaney A ($A_{12}$)**:
  The $A_{12}$ statistic is the probability that a value from Group 1 is larger than a value from Group 2, plus half the probability of a tie:
  $$A_{12} = P(X_1 > X_2) + 0.5 \times P(X_1 = X_2)$$
  $A_{12} \in [0, 1]$, where $A_{12} = 0.5$ represents complete distributional overlap.

- **Exact Linear Relationship**:
  Since $P(X_1 > X_2) + P(X_1 < X_2) + P(X_1 = X_2) = 1$, we can substitute $P(X_1 < X_2) = 1 - P(X_1 > X_2) - P(X_1 = X_2)$ into the formula for Cliff's Delta:
  $$\delta = 2 P(X_1 > X_2) + P(X_1 = X_2) - 1 = 2 A_{12} - 1$$
  Therefore, we have the exact linear relationship:
  $$A_{12} = \frac{\delta + 1}{2}$$

### 3.2. Interpretation Thresholds
The effect size magnitudes are categorized according to standard literature thresholds:

| Magnitude | Cliff's Delta Range ($|\delta|$) | Vargha-Delaney A Range ($|A_{12} - 0.5|$) |
|---|---|---|
| **Negligible** | $[0.000, 0.147)$ | $[0.000, 0.0735)$ |
| **Small** | $[0.147, 0.330)$ | $[0.0735, 0.1650)$ |
| **Medium** | $[0.330, 0.474)$ | $[0.1650, 0.2370)$ |
| **Large** | $\geq 0.474$ | $\geq 0.2370$ |

*Note: Alternative literature defines the Vargha-Delaney thresholds as Negligible $< 0.056$, Small $\geq 0.056$, Medium $\geq 0.14$, and Large $\geq 0.21$. We recommend providing both or using the mapped Cliff's Delta thresholds for mathematical consistency.*

### 3.3. Optimized $O(n \log n)$ Vectorized Implementation
A naive double-loop calculation of Cliff's Delta requires $O(n_1 \cdot n_2)$ comparisons, which is computationally prohibitive for concatenated multi-seed error series (where $N = 5 \times 600 = 3000$, resulting in $9 \times 10^6$ iterations).
We can compute the metrics in $O(n \log n)$ time using the Mann-Whitney U statistic:
1. Combine Group 1 ($X_1$) and Group 2 ($X_2$) into a single array and compute their ranks (handling ties with the average rank).
2. Calculate the rank sum of Group 1, denoted as $R_1$.
3. Compute the Mann-Whitney $U_1$ statistic:
   $$U_1 = R_1 - \frac{n_1(n_1 + 1)}{2}$$
4. Calculate $A_{12}$ and $\delta$:
   $$A_{12} = \frac{U_1}{n_1 n_2}$$
   $$\delta = 2 A_{12} - 1$$

Python implementation via `scipy.stats.mannwhitneyu`:
```python
from scipy.stats import mannwhitneyu

def compute_effect_size_fast(group1, group2):
    n1, n2 = len(group1), len(group2)
    # mannwhitneyu returns U statistic for group1
    res = mannwhitneyu(group1, group2, alternative='two-sided')
    U1 = res.statistic
    a12 = U1 / (n1 * n2)
    delta = 2 * a12 - 1
    return delta, a12
```

### 3.4. Comparison Order Convention
To ensure clear interpretations of the results:
- **Group 1 ($X_1$)**: Baseline model absolute errors ($|e_{\text{baseline}}|$).
- **Group 2 ($X_2$)**: GUMNet model absolute errors ($|e_{\text{GUMNet}}|$).
- **Interpretation**: Under this convention, if GUMNet outperforms the baseline, GUMNet's errors will be smaller, making the baseline errors larger. This leads to $\delta > 0$ and $A_{12} > 0.5$.
  - $\delta > 0, A_{12} > 0.5$: GUMNet is superior (smaller errors).
  - $\delta < 0, A_{12} < 0.5$: Baseline is superior.

## 4. Formulation of `compile_32model_results.py` Metrics

The script must compile the results from all 32 models across the 7 horizons and 5 seeds. It should load the `predictions.csv` files and calculate the metrics below.

### 4.1. Point Forecast Metrics
- **MAE (Mean Absolute Error)**:
  $$MAE = \frac{1}{N} \sum_{i=1}^N |y_i - \hat{y}_i|$$
- **RMSE (Root Mean Squared Error)**:
  $$RMSE = \sqrt{\frac{1}{N} \sum_{i=1}^N (y_i - \hat{y}_i)^2}$$
  Where $y_i$ is the actual price (`true`) and $\hat{y}_i$ is the point forecast (`pred`). For multi-product target settings (e.g. MG95 and MG92 in XANG), these metrics are averaged across all products and dates in the test set.

- **DA (Directional Accuracy)**:
  DA measures the percentage of correct directional predictions. To ensure robustness across varying numbers of target products (2 for XANG/DAU, 4 for BOTH), we formulate a group-by approach:
  $$\text{DA} = \frac{1}{P} \sum_{p=1}^P \left( \frac{1}{T - 1} \sum_{t=2}^T I\left(\text{sign}(y_{p, t} - y_{p, t-1}) == \text{sign}(\hat{y}_{p, t} - \hat{y}_{p, t-1})\right) \right) \times 100\%$$
  where $P$ is the number of products and $T$ is the number of chronological test days.
  ```python
  def compute_da(df):
      da_correct = []
      for prod, group in df.groupby('product'):
          group = group.sort_values('date')
          true_vals = group['true'].values
          pred_vals = group['pred'].values
          if len(true_vals) > 1:
              true_dir = np.sign(np.diff(true_vals))
              pred_dir = np.sign(np.diff(pred_vals))
              correct = (true_dir == pred_dir).astype(float)
              da_correct.extend(correct)
      return np.mean(da_correct) * 100 if da_correct else 0.0
  ```

### 4.2. Interval Forecast Metrics
- **PINAW (Prediction Interval Normalized Average Width)**:
  PINAW evaluates the sharpness of the prediction intervals (10% and 90% quantiles) normalized by the range of the actual values.
  
  We propose two normalization methods:
  1. **Standard PINAW**: Uses the empirical range of the actual test set values:
     $$PINAW = \frac{\frac{1}{N} \sum_{i=1}^N (q_{90, i} - q_{10, i})}{\max(y_{\text{true}}) - \min(y_{\text{true}})}$$
  2. **Robust PINAW**: Normalized by $4 \times \text{Std}(y_{\text{true}})$ (implemented in `compute_advanced_metrics.py`). This prevents outliers or extreme price spikes (e.g. during geopolitical crises) from artificially inflating the range, which would deceptively deflate the PINAW score.
     $$PINAW_{\text{robust}} = \frac{\frac{1}{N} \sum_{i=1}^N (q_{90, i} - q_{10, i})}{4 \times \text{Std}(y_{\text{true}}) + 1e-8}$$
  We recommend using the robust PINAW to maintain alignment with the calibration analysis in the research paper.

### 4.3. New Results Only Filtering
To ensure that only newly generated runs are aggregated in the compilation script, we implement timestamp filtering using the `--min-timestamp` CLI argument:
1. Load `results.json` for each model run.
2. Read the `"datetime"` field (representing the UTC completion timestamp).
3. If the `"datetime"` field is missing, fall back to the file modification time (`os.path.getmtime`).
4. Filter out runs where the run completion time is older than the `--min-timestamp` argument.
```python
from datetime import datetime

def check_timestamp(res_file, min_timestamp_str):
    if not min_timestamp_str:
        return True
    
    # Parse min_timestamp CLI argument (e.g. "2026-07-17T00:00:00Z")
    min_dt = datetime.fromisoformat(min_timestamp_str.replace('Z', '+00:00'))
    
    with open(res_file, 'r') as f:
        data = json.load(f)
    
    dt_str = data.get('datetime')
    if dt_str:
        file_dt = datetime.fromisoformat(dt_str.replace('Z', '+00:00'))
    else:
        # Fallback to file system modification time
        mtime = os.path.getmtime(res_file)
        file_dt = datetime.fromtimestamp(mtime, tz=timezone.utc)
        
    return file_dt >= min_dt
```

## 5. Summary of Proposed Implementations

### 5.1. Script: `scripts/dm_test_32models.py`
This script should:
1. Load `predictions.csv` for GUMNet and all baselines.
2. Concatenate prediction/true arrays across the 5 seeds to form a unified test series for each model, target, and horizon.
3. Compute the pairwise DM statistic matrix for all 32 models using the HLN correction and Newey-West HAC estimator with Bartlett kernel lag $q = \max(0, \min(h - 1, \lfloor 1.2 T^{1/3} \rfloor))$.
4. Run the joint MCS test using a moving block bootstrap ($B = 1000$, block size $p = \lfloor T^{1/4} \rfloor$), pre-generating bootstrap indices and using sample HAC variance scaling for speed.
5. Save the outputs: `dm_pvalue_matrix_{horizon}.csv` and `mcs_superior_set.csv`.

### 5.2. Script: `scripts/effect_size_32models.py`
This script should:
1. Load `predictions.csv` and extract absolute errors for GUMNet and all 31 baseline models.
2. Concatenate errors across the 5 seeds.
3. Compute Cliff's Delta ($\delta$) and Vargha-Delaney $A_{12}$ using the fast rank-based Mann-Whitney U method.
4. Establish Group 1 as the baseline and Group 2 as GUMNet, so that a positive $\delta$ and $A_{12} > 0.5$ reflect GUMNet superiority.
5. Save the output: `effect_size_matrix.csv`.

### 5.3. Script: `scripts/compile_32model_results.py`
This script should:
1. Scan `results_v4/walkforward` for `results.json` and `predictions.csv` files.
2. Filter files using the `--min-timestamp` argument against the `"datetime"` JSON field.
3. For each model, target, and horizon, calculate the mean and standard deviation of MAE, RMSE, DA, and PINAW across the available seeds.
4. Export the detailed aggregation to `compiled_32model_results.csv`.
5. Group models by their paradigm registry and export the average performance to `compiled_32model_results_by_paradigm.csv`.
